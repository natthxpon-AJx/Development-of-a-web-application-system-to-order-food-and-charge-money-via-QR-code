# การเชื่อมต่อ API

Frontend เรียก API ผ่าน `api.js` ตั้ง URL ได้ด้วย `VITE_API_URL` (ค่าเริ่มต้น `http://localhost:4000/api`)

Backend หลักอยู่ที่ `chamakmai-app/backend/` ให้ใช้ไฟล์ `.env`, schema และคำสั่งเริ่มระบบจากที่นั่น ดู [คู่มือ backend](../../../backend/README.md)

`server.js` ในโฟลเดอร์นี้เป็นตัวเรียก backend หลักเพื่อรองรับคำสั่งเก่า ไม่ใช่ API อีกชุดหนึ่ง ไฟล์ schema เดิมในโฟลเดอร์นี้เป็นข้อมูลเก่า ไม่ต้อง import ซ้ำกับฐานข้อมูลที่ใช้งานอยู่

การเข้าสู่ระบบใช้ sessionStorage พร้อม token และเวลาหมดอายุ API ทุกส่วนหลังร้านตรวจสิทธิ์บน server ส่วนคำขอลูกค้าต้องระบุรหัสโต๊ะตามหน้าที่เปิดใช้งาน
